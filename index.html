Story

ストーリー

誰ひとり、最上階へ辿り着いた者のいない塔がある。
《逆流魔塔》。
塔の階段は、強力な魔力によって封印されている。冒険者たちは《封印束》の札を使い、封印を解除しながら上階を目指した。 だが、力任せに封印を破壊した者は、必ず塔に呑まれた。あふれた魔力に塔が反応する。 解除したはずの封印は再び現れ、塔は成長する。

調査の末、古い記録からひとつの法則が見つかった。
《完全一致》
封印は、余剰なく解除した時だけ逆流を起こさない。
あなたは調査者として、誰も辿り着いたことのない魔塔最上階を目指す。そこには、世界の理を変える何かが眠ると言われている…

Game Overview

ゲーム概要

プレイヤーは《手札》から札を《展開域》へ展開し、塔の最下層から「封印」を解除して上階を目指す。 解除した封印札と使用した札は《魔力の壺》へ蓄積される。 しかし、強すぎる力で封印を解除すると《逆流》が発生し、《魔力の壺》に蓄積された札が再び塔へ戻ってしまう。 また、封印解除に失敗すると《侵食》を受け、《封印束》が少しずつ失われていく。 《封印束》が尽きる前に塔を踏破せよ。

《完全一致》による封印解除こそが、終わりなき魔塔を攻略する鍵となる。

カード数値

  • 2〜10 : 数字通り
  • J : 11

Game Areas

ゲーム領域

  • 封印束 (山札) — 手札の補充・侵食ダメージ・浄化に使用。裏向きで配置。
  • 塔 — 攻略対象。一番下のカードが現在解除すべき封印。インデックスが見える状態で表向きに縦一列に重ねて並べる。
  • 手札 — 現在使用できる札。
  • 展開域 — 手札から出した札をプレイする場所。解除成功まで場に残り続ける。表向きで左から右に配置。
  • 魔力の壺 — 使用済みの札・解除した封印札を置く場。《逆流》発生時、ここから札を塔へ戻す。表向きで積み上げる。
  • 侵食域 — プレイヤーが受けたダメージ。封印束から裏向きでカードを並べる。新しいカードが右端になるように重ねて並べる。

2

— 上から下に重ねるように配置する。
3
封印束から「手札」を4枚引く。
Turn Flow

ターンの流れ

1
ドロー
封印束から1枚引き、手札に加える。
封印束が0枚の場合は何もしない。ドローができない場合は敗北にはならない。
2
札を展開する
手札から1枚選び、展開域へ表向きで配置する。展開域にある札の数値合計が、現在の封印への干渉値となる。

展開域 (例 : 干渉値 6)
A(1) + 5 = 6
3
侵食判定
現在解除すべき封印の数値を封印値と呼ぶ。干渉値が不足している場合に侵食が発生する。
侵食値の計算
侵食値 = 封印値 − 干渉値
侵食値が1以上の場合、その数値分だけ封印束の上からカードを裏向きで侵食域へ移動する。
必要枚数を置けない場合、その時点で敗北。
4
封印解除判定
干渉値が封印値以上になれば解除成功。
余剰値の計算
余剰値 = 干渉値 − 封印値
5
封印解除時のスート処理
解除成功時、最後に展開した札のスートに応じて以下の効果が発生する。
♠
スペード「暴走」
余剰値が + 2 される。
(干渉値が増えるわけではないことに注意)
♣
クラブ「封鎖」
最終的な余剰値を 0 にする。
★
共鳴
封印のスートと最後の展開札のスートが同じ場合、余剰値が − 1 される。 (0未満にはならない)
6
安定化処理
最後に展開した札が ♥ または ♦ の場合、以下の効果が発生する。
♥
ハート「浄化」
最後に展開した ♥ の数値 ÷ 2 (切り捨て) の枚数だけ、侵食域から封印束の下に札を戻す。
♦
ダイヤ「解析」
魔力の壺の一番上の札1枚を封印束の下に戻す。
7
魔力の壺への蓄積と逆流
解除に成功した場合、以下の順で処理する。
1.
逆流 : 現在の余剰値の数だけ、魔力の壺の上から順に表向きで塔の一番上へ戻す。
2.
解除した封印を魔力の壺に表向きで移動する。
3.
展開域の札をすべて魔力の壺に表向きで移動する。
塔に戻してから解除に使った札を魔力の壺へ移動する。

ジョーカー

ジョーカー

数値・スートを持たない特殊な札。

手札から使用時 : 現在の封印を「余剰 0」で即座に解除。
スートを持たないため、解除した封印とジョーカーを魔力の壺に表向きで移動してターンを終了する。
塔に存在時 : 任意の数値カード1枚で無条件解除。
最後にプレイした札が ♥ または ♦ の場合は効果を発動させる。
Victory & Score

勝敗とスコア計算

勝利条件
塔のカードをすべて解除した時点で勝利。
敗北条件
侵食ダメージを受ける際、封印束のカードが不足した時点で敗北。

スコア計算

1
踏破数
EASY / NORMAL : 12 − 塔の山枚数
HARD : 16 − 塔の山枚数
2
基礎点 = (踏破数 × 10) + 封印束の残枚数 − (侵食枚数 × 2)
3
スコア = 基礎点 × 難易度倍率 (小数点以下切り捨て)
難易度 スコア倍率
EASY × 0.8
NORMAL × 1.0
HARD × 1.5
Play Samples

プレイサンプル

1. 基本的な被ダメージ
塔
展開域
封印値 : 13 干渉値 : 11
  1. 侵食判定 : 13 − 11 = 2
    干渉値が不足しているため、侵食 2枚を受ける。封印束から2枚を侵食域に移動する。
封印は解除されず、このターンは終了。
♠ を展開しているが、干渉値に + 2 する能力ではないことに注意 (余剰値への加算のみ)。
2. 複数スート効果による余剰計算 (♠ 暴走 + ♠ 共鳴)
塔
展開域
封印値 : 4 干渉値 : 5 魔力の壺 : 1枚
  1. 封印解除判定 : 5 ≥ 4 → 解除成功！
  2. 基本余剰 : 5 − 4 = 1
  3. 効果の適用 :
    ♠ 暴走 : 余剰 + 2 = 3
    ♠ 共鳴 (スートが同じ) : 余剰 − 1 = 2
  4. 魔力の壺への蓄積と逆流 :
    逆流 : 余剰値2なので、魔力の壺の上から1枚 (1枚しかないため) を塔の一番上へ戻す。
    ♠4 (解除した封印) → 魔力の壺へ
    ♠5 (展開域の札) → 魔力の壺へ
塔を1階層登ったが、新しい封印が積まれる。
3. ハートによる侵食の回復 (♥ 浄化)
塔
展開域
封印値 : 8 干渉値 : 8 侵食域 : 3枚
  1. 封印解除判定 : 8 ≥ 8 → 解除成功！
  2. 基本余剰 : 8 − 8 = 0
  3. 安定化処理 :
    ♥5 が最後の展開札 → ♥ 浄化が発動。 (♥3 は「最後の展開」ではないため対象外)
    5 ÷ 2 (切り捨て) = 回復量 2
    侵食域の右から2枚を封印束の下に戻す。
  4. 逆流 : 余剰値0 → 塔に札は戻らない。
    ♠8 (解除した封印) → 魔力の壺へ
    ♥3・♥5 (展開域の札) → 魔力の壺へ
侵食ダメージを2枚回復しながら封印を解除。
4. ♣ で逆流を完全に抑制 (♣ 封鎖)
塔
展開域
封印値 : 1 干渉値 : 13
  1. 封印解除判定 : 13 ≥ 1 → 解除成功！
  2. 基本余剰 : 13 − 1 = 12
  3. 効果の適用 :
    ♣ 封鎖 : 余剰12 → 0 に変更。
  4. 逆流 : 余剰値0 → 塔に札は戻らない。
    ♥1 (解除した封印) → 魔力の壺へ
    ♣K (展開域の札) → 魔力の壺へ
強い力で解除しても完全一致の恩恵を受ける。
5. ♦ による安定化処理と効果の発動範囲
塔
展開域
封印値 : 11 干渉値 : 14 魔力の壺 : 1枚
  1. 基本余剰 : 14 − 11 = 3
  2. 効果の適用 :
    ♦ 共鳴 (スートが同じ) : 余剰 − 1 = 2
    前のターンで展開した ♣ 封鎖はこのターンでは発動しない。
  3. 安定化処理 :
    ♦9 が最後の展開札 → ♦ 解析が発動。
    魔力の壺の上から1枚を封印束の下に戻す。 (魔力の壺が0枚に)
  4. 逆流 : 余剰値2だが、魔力の壺に札がないため塔に戻す札がない。
    ♦J (解除した封印) → 魔力の壺へ
    ♣5・♦9 (展開域の札) → 魔力の壺へ
処理の順番を支配することで逆流を制御できる。
